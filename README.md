# Flappy Dragon (beta)

A dragon-flying siege game made with pygame.

## Getting the beta (for testers)
1. Open the **Releases** page of this repository on your Android phone.
2. Under the newest **Flappy Dragon beta**, tap the `.apk` file to download it.
3. Open the download. If your phone asks, allow your browser (or Files app) to **install unknown apps**.
4. Tap **Install**, then open Flappy Dragon.

New betas install over the old one, and your save is kept.

## Building
Every push to `main` builds a new APK automatically (see the **Actions** tab)
and publishes it as a beta release. A build takes about 40-60 minutes the first time
and about 15-25 minutes after that.

## Running on a phone without installing
Copy all the `.py` files into one folder and run `flappy_dragon.py` in Pydroid 3.
